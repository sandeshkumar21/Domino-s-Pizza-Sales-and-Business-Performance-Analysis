# Dataset

Place your existing CSV here:

`data/dominos_sales.csv`

The SQL scripts are designed around the current single-table dataset.

Expected columns:

`order_id, order_date, order_time, customer_id, store_id, city, order_type, payment_method, pizza_id, pizza_name, category, size, quantity, unit_price, discount_amount, delivery_minutes`

For GitHub, do not upload the raw CSV if its dataset license does not allow redistribution.
